About Me:

This site was created by an aspiring cybersecurity professional, currently working as a SOC analyst. My purpose in creating HighLion is to have a platform in which I can develop and expand my web design and defense planning skills, as well as practice penetration testing on a live website.

Hosting
Self-hosted on Debian, with nginx serving the site and PHP handling the APIs.
Stack
HTML and CSS for the pages, JavaScript for the terminal and live panels, and PHP for contact and server data.
Lab Purpose
A working lab for testing web defenses, building tools, and publishing what I learn from security research.
