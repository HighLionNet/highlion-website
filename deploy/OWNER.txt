HIGHLION DEBIAN CUT-IN (HLv8 / hl8g)
1. rsync repo → /var/www/highlion
   do not rsync .git
2. Delete dead disk-only junk:
     sudo rm -f /var/www/highlion/assets/audio/ui-blip.wav
     sudo rm -f /var/www/highlion/assets/resume.pdf
3. Fonts:
     sudo bash /var/www/highlion/assets/fonts/generate-fonts.sh
4. Telegram secrets (already on the Pi — confirm mode):
     sudo install -d -m 0750 -o root -g www-data /etc/highlion
     sudo chmod 640 /etc/highlion/letterbox.env /etc/highlion/honeypot.env
     sudo chown root:www-data /etc/highlion/letterbox.env /etc/highlion/honeypot.env
     each file:
       TELEGRAM_BOT_TOKEN=...
       TELEGRAM_CHAT_ID=...
     two different bots. letterbox.env = real messages.
     honeypot.env = pot trips only.
5. Disable the watcher and unused MTA:
     sudo systemctl disable --now highlion-honeypot-watch.service || true
     sudo systemctl disable --now postfix || true
6. nginx:
     sudo cp /var/www/highlion/deploy/nginx-api.conf \
             /etc/nginx/snippets/highlion-api.conf
     inside www.highlion.net server block:
       include snippets/highlion-api.conf;
     replace any add_header X-HighLion v6 with
       add_header X-HighLion "HLv8" always;
     EXCLUDE ^/api/ from the IL geo map that wraps /contact.html
     nginx -t && sudo systemctl reload nginx
7. Traffic board:
     sudo usermod -aG adm www-data
     sudo systemctl restart php-fpm
     if count stays 0, the tunnel access log format needs a
     one-line sample pasted into /var/tmp/nginx-access.sample
     so the parser can be adjusted next pass. Do not fake it.
8. Tests:
     curl -sI https://www.highlion.net/api/csrf.php           → 200
     curl -s  https://www.highlion.net/api/intel.php          → 8 mixed hosts
     curl -s  https://www.highlion.net/api/traffic.php        → json
     curl -sI https://www.highlion.net/css/style.css?v=hl8g   → 200
     off-IL: curl -sI https://www.highlion.net/contact.html   → 403
     any-IP POST /api/contact.php is NOT geo-blocked
     POST company:"bot" → 200 ok + new line in
       /var/tmp/highlion-honeypot.log + honeypot Telegram
     POST a real message → letterbox Telegram, no mail() in logs
